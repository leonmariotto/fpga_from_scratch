# Chapter 1 : From zero to one.

Microprocessors revolution in the past 3 decades have enabled improvements 
in many fields: automobile, space, cell phone, internet.

## Managing complexity

The key is **abstraction**, build complex block by assembling complexe 
abstracted block, new block become a new abstracted block for a upper layer.
**Digital circuit** is a special case of **analog circuit**.
**Microarchitecture** is the logic-level implementation of an **architecture** 
which is a description of a circuit from the programmer perspective.

```mermaid
flowchart LR
    phy["Physics: atoms, electrons"]
    devices["Devices: transistors, diode, ..."]
    analog_circuit["Analog Circuit: amplifier, filter, ..."]
    digital_circuit["Digital Circuit: AND gates, NOT gates, ..."]
    logic["Logic: Adder, memory, ..."]
    microarchitecture["Microarchitecture: datapaths, controller, ..."]
    architecture["Microarchitecture: instructions, register, ..."]
    os["Operating System: drivers, scheduler, ..."]
    app["Application Software: programs, ..."]
    phy -> devices
    devices -> analog_circuit
    analog_circuit -> digital_circuit
    digital_circuit -> logic
    logic -> microarchitecture
    microarchitecture -> architecture
    architecture -> os
    os -> app
```
